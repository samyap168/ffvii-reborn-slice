# FINAL FANTASY VII — Reborn · a fan-tribute vertical slice

A non-commercial fan tribute that reimagines a slice of the 1997 original as a
modern, cinematic real-time experience running entirely in the browser:
Cloud riding a golden Chocobo across an open landscape, a monster encounter,
real-time Buster Sword combat with materia magic, an enraged serpent boss,
a Limit Break, and a Knights of Round summon.

**Everything is procedural.** There are no downloaded meshes, textures,
samples or music files: terrain, vegetation, water, ruins, characters,
creatures, animation, VFX, sound design and the score are all generated by
code at load time. (Web fonts are loaded from Google Fonts.)

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

Requires a modern desktop browser. WebGPU is used when available (Chrome/Edge),
otherwise it falls back to WebGL2 automatically. Add `?gl` to force WebGL2 and
`?q=low|medium|high|ultra` to pick a quality preset.

## Tech

- three.js r186 `WebGPURenderer` + TSL node materials (WebGL2 fallback)
- Geometry-clipmap terrain (single draw call, CDLOD morphing) on a generated heightfield
- GPU-generated grass (blades placed from `instanceIndex`), instanced trees/rocks with LOD
- Cascaded shadow maps, height fog / aerial perspective, procedural sky with clouds
- Post: motion blur, sun shafts, depth of field, bloom, grading, chromatic aberration, FXAA
- Web Audio: fully synthesized SFX, spatial audio and a dynamic, state-driven score
